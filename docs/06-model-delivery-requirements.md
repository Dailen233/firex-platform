# 双江口正式模型交付说明

本月目标是能浏览双江口电站、周边山地及一段线路。约100km²指整个研究区；实际模型覆盖不足时报告实际边界，不拉伸模型凑面积。

| 项目 | 需要交付或说明 | 尚未确定时 |
|---|---|---|
| 文件与版本 | 首选适合当前Three.js流程的glTF2.0/GLB；其他格式也可先交源文件、说明软件与版本，收到后再判断转换方案 | 写明原始格式，不能把后缀改成.glb冒充转换 |
| 贴图 | 提供全部贴图和相对路径；GLB尽量内嵌；说明材质、透明/双面设置、所需压缩扩展 | 缺贴图列出清单 |
| 数据许可 | 来源、取得方式、可用于研究/展示/再次分发的范围 | 标注许可待确认 |
| 覆盖范围 | 经纬度/投影坐标边界GeoJSON或可靠角点；包含哪些电站设施、山地、线路 | 仅有模型包围盒时列“局部范围，地理范围待定位” |
| 水平坐标系 | EPSG代码或完整WKT/PROJ；WGS84/CGCS2000/GCJ-02等不得混用 | 保留原坐标数值，写待确认 |
| 单位 | 米/厘米等；说明是否经过缩放 | 可结合已知尺度检查，不能盲目假设米 |
| 朝向与轴 | 右/左手系、上轴、北向、旋转角、投影格网与真北关系 | 记录为未知，靠文件/对应地物核对 |
| 水平原点 | 本地原点对应的E/N或经纬度；偏移是否已烘焙到顶点/根节点 | 原点未知则正式定位待核 |
| 高度 | EGM2008/1985国家高程/椭球高/自定义局部高度；高度原点与减去的偏移 | 不猜高程；禁止把相对模型高度写成AGL |
| 变换 | 模型局部坐标到地理参考框架的矩阵或完整换算；明确矩阵顺序、轴和单位 | 不改原始模型，先在外部适配器中记录候选变换 |
| 对应特征 | 建议至少3个不共线的可识别对应点，给局部XYZ和地理坐标/来源/精度；有可靠高度的点另标 | 公开地图参考点可用于初步对齐，不能当作测量控制点 |
| 地形与对象 | 地形网格如何识别；电站/坝体/塔位等对象名称或可选对象表 | 无对象表仍可浏览；无地形采样能力则暂不贴地叠加 |
| 线路 | 路线GeoJSON/塔位表、线路名称/电压/归属、塔和导线高度的基准 | OSM周边参考线与正式送出工程分开，不补造高度 |
| 数据年代 | 采集/制作时间、是否包含当前大坝与蓄水现状 | 写明不清楚，不用公开老DSM推断现在设施 |
| 性能信息 | 文件/贴图大小、网格/三角形/材质数量；不预设分块方案 | 到手后量测，再选择优化策略 |

glTF2.0规范采用右手坐标、Y向上、线性单位为米，但导出是否规范、实际地理北向以及模型原点仍须检查。参考：https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html

队友可以先给模型文件与已有说明。缺少资料时由我们检查文件、公开地图与可识别地物，逐项补齐；无法核实的部分继续写“待定位/待确认”。无需为了交付而编造坐标表。
