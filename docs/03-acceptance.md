## 双江口参考底座接入（R3，本轮）

2026-10-11，分支 `feat/shuangjiangkou-prep`。基于 `FireX_Shuangjiangkou_Resources_20261011` 资源包完成配置解耦与公开 DSM 山地参考底座接入；正式模型仍标注待接入。

### 已完成

- **配置解耦**：新增统一 `SceneProfile`，场景名称、资源路径（模型/对象表/标记）、相机（默认/厂区/全域/全景）、统计（字节/SHA/顶点/三角形）与能力开关（对象选择/参考标记/火区覆盖层）均通过 `scene_profile.json` 读取。织金与双江口各一份 profile，`scene_index.json` 记录 `asset_role` + `profile_uri`。viewer/SceneView/SceneCanvas 不再硬编码织金 ID、38 对象、固定 6.72MB。
- **双江口第 8 厂**：地图参考点取自包内 OSM 坝体多边形质心（101.92362°E, 31.79276°N），标注“公开地图参考，非测量定位”。设计装机 2000 MW（4×500 MW）与“截至 2026-08-31 三台投运（3×500 MW）”分开；`formal_model_status:"awaiting_file"`、`scene_ready:false`。
- **参考底座预览**：接入包内 `terrain_reference.glb`（2,416,736 字节，40,401 顶点 / 80,000 三角形，SHA 已核对），提供“浏览山地参考底座”入口，`scene_id=shuangjiangkou_reference_terrain`、`asset_role=public_reference_terrain`。复用加载进度、失败重试、全景取景与恢复默认视角；未知下载总长不伪造百分比。
- **三个参考标记**：改用包内有来源的 OSM 点（坝体轮廓 / 开关站轮廓 / 周边线路塔位），绑定 `scene_id + asset_version + coordinate_frame_id`，3D 标记与数据级展示一致；旧 SJK-DAM/LINE/MOUNTAIN 无来源坐标已移除。
- **坐标口径**：参考底座 `EPSG:32647 (UTM47N)`，`X=E−E0、Z=N0−N、Y=H_EGM2008−2000`（Y 非 AGL）；正式模型原点/朝向/单位/高程基准仍为空，`formal_model_registration.status="pending_file"`，不套用织金 UTM48N 坐标。
- **检查**：`npm run test:data`（21 项，含 SJK-01..05 边界检查）、`npm run build`（退出 0）、`git diff --check`（退出 0）本机通过。织金 38 对象 / 原 SHA / 根变换 / R2 演示火区回归保留。

### 口径与未验证项

- ~100 km² 为**建议研究区**（`is_proposed:true`，可调整），非已渲染模型面积，也不表示队友模型已覆盖该范围。
- 参考 GLB 为 Copernicus GLO-30 DSM（约 30m，2011–2015 主要采集），非当前大坝/厂区精细模型；颜色仅为高程示意。
- 三个标记的 3D 高度为参考表面 +1m 显示偏移，非设施/杆塔实测高度；线路几何归属待与官方 500 kV 送出工程核实。
- 参考底座可用于加载与坐标流程测试，但不代表正式模型到地理坐标的真实配准。
